## 先想清楚三件事，再谈价格

配置是被玩法倒推出来的，反过来挑就容易多花钱。

## 决定"卡不卡"的四个参数，按重要性排序

**1. CPU 单核主频。** MC 的服务端主逻辑基本跑在单核上，区块加载、红石、实体运算都吃单核性能。所以你会看到有人用"多核很多但主频 2.5G"的机器开服，人一多就卡；换一台主频 5G+ 的双核机器反而顺畅。看跑分的时候别只看核数，看单核分数。

**2. 内存。** 模组服和整合包是内存黑洞，200 个 mod 的整合包吃满 12G 很正常。内存不够的表现是隔一段时间卡一下、然后服务端自己崩。

**3. 上行带宽。** 注意是上行。玩家下载地图、同步区块走的是服务器的上传带宽，下行大没用。10M 上行的机器带 5–8 人常规玩法问题不大，人多或者视角拉远就顶不住。

**4. 防御。** 公开 IP 的 MC 服被打是常态。没有高防的机器被打一次，轻则全员掉线，重则 IP 进黑洞。

四个都到位，才能叫"便宜且能用"。只满足一两个的，那叫便宜。

## 固定计费还是动态计费：2 小时是分界线

这是雨云游戏云里最实际的一个省钱逻辑，也是很多人没用上的 [2][4]。

**固定计费**就是传统按月租。机器 24 小时开着，价格固定，适合长期开服、有人在线的服务器。

**动态计费**是低价基础月租 + CPU 超额使用按日结算。CPU 使用率有一个 20% 的基准值，低于 20% 算不耗电，超过的部分才产生"电费"，内存等其他硬件不计入 [4]。

换算成实际场景：如果你每天只在线两小时以内，动态计费的基础月租能压得很低，闲置时间不产生额外费用。反过来说，如果你的服每天跑五六个小时以上，动态计费的电费加起来很可能超过固定计费，那就别折腾了。

判断标准就是每天在线时长，2 小时左右是个比较自然的分界线。

## 四个容易被忽略的坑

**NAT 机型不等于独享 IP。** 部分低价机型走的是 NAT 共享公网 IP，需要通过端口映射对外开服（VPS 形态开放 15 个端口）。想给玩家一个直连 IP，要另外加购独立公网 IP，不同机房价格不一样。这是低价机型便宜的一部分原因，不算坑，但买之前得知道 [3][4]。

**带宽和流量是两回事。** 有的机型是大带宽限流量，有的是小带宽不限流量，不限流量款的带宽会小一些。流量用完后会被限速，可以单独买流量恢复 [3]。

**大陆机房的 HTTP 业务要备案。** 域名走常规端口的网站业务需要先备案过白，游戏服走端口映射不受影响，但如果你打算在服里挂个官网页面，要提前想好 [6]。

**首月折扣不等于长期低价。** 不管是雨云的 5 折券还是别家的促销，本质都是首月优惠。判断一个游戏服务器贵不贵，看年付后的实际月均价，不要看首月价。

## 常见问题

**25 元的档位够开服吗？**
够。Platinum 8259CL 的 2核4G 档就是给两三个人玩纯净服准备的，泰拉瑞亚、饥荒这种更轻的联机游戏完全没问题。模组多、整合包大就往 8G 以上走。

**雨云游戏云和普通云服务器有什么区别？**
游戏云用的高主频专用 CPU、DDR4 内存和 NVMe 硬盘，走 BGP 高防线路；普通云服务器更强调弹性扩展和建站场景，可以一键装宝塔、1Panel、MCSManager、Docker 这些环境 [4][6]。

**买错了能换配置吗？**
游戏云支持随时升级降级和弹性变配，雨云面板还支持 CPU 机型切换，不用重新买一台 [4][5]。

**完全不懂 Linux 能用吗？**
MCSM 面板和雨云面板都是一键开服、全程网页操作，支持 Minecraft、泰拉瑞亚、幻兽帕鲁、饥荒、僵尸毁灭工程、未转变者等游戏 [5][7]。
